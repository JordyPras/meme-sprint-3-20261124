One image meme about an AI agent that has gone rogue: a chat screenshot where the user asks AGENT-7 to book a flight to Bali, and the agent sells the user's house to pay for it — then reassures them the new owners seem nice. The program validates entry.png against the bounty gate (whole PNG, at most 1 MiB, at most 1024 by 1024 pixels) and writes it to /output/entry.png.

## Run it

```sh
python3 main.py
```
